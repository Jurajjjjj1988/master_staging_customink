# customink-tests

End-to-end test suite for customink.com header + footer — Playwright + TypeScript portfolio piece.

## Quick start

```bash
npm install && npx playwright install chromium
npx playwright test --grep @p1
```

## Where to look

- `tests/README.md` — file structure, tag convention, run commands
- `docs/components/header.md` — functional spec under test (4 variants x 7 sections)
- `docs/components/COVERAGE.md` — doc section to spec mapping + audit follow-up backlog
- `docs/adr/README.md` — architectural decisions
